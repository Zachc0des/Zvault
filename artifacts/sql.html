📊 Beginner's Guide to SQL

Master the language of databases with interactive examples

What is SQL?

SQL (Structured Query Language) is a programming language designed for managing and manipulating data in relational databases. It's the standard language for relational database management systems.

Why Learn SQL?

  • Used by data analysts, scientists, and engineers worldwide
  • Essential for working with databases
  • Relatively easy to learn compared to other programming languages
  • In high demand across industries

Sample Database: Students

Throughout this guide, we'll use a simple students database:

SELECT Statement

The SELECT statement is used to retrieve data from a database. It's the most commonly used SQL command.

Basic Syntax

SELECT column1, column2
FROM table_name;

Examples

Select All Columns

SELECT *
FROM students;

Returns all columns and all rows from the students table.

Select Specific Columns

SELECT name, major
FROM students;

Returns only the name and major columns.

💡 Tip: Using * selects all columns, but it's better practice to specify column names for better performance and clarity.

WHERE Clause

The WHERE clause filters records based on specified conditions.

Basic Syntax

SELECT column1, column2
FROM table_name
WHERE condition;

Common Operators

=

Equal to

WHERE age = 20

!=, <>

Not equal to

WHERE grade != 'A'

>, <, >=, <=

Comparison operators

WHERE age >= 21

LIKE

Pattern matching

WHERE name LIKE 'A%'

IN

Match any value in list

WHERE major IN ('CS', 'Math')

BETWEEN

Range of values

WHERE age BETWEEN 20 AND 22

Examples

-- Find all Computer Science students
SELECT *
FROM students
WHERE major = 'Computer Science';

-- Find students older than 21
SELECT name, age
FROM students
WHERE age > 21;

-- Find students with grade A or B
SELECT *
FROM students
WHERE grade IN ('A', 'B');

JOIN Clauses

JOINs combine rows from two or more tables based on a related column.

Types of JOINs

INNER JOIN

Returns records with matching values in both tables.

SELECT students.name, courses.course_name
FROM students
INNER JOIN enrollments ON students.id = enrollments.student_id
INNER JOIN courses ON enrollments.course_id = courses.id;

LEFT JOIN

Returns all records from the left table and matched records from the right table.

SELECT students.name, enrollments.course_id
FROM students
LEFT JOIN enrollments ON students.id = enrollments.student_id;

RIGHT JOIN

Returns all records from the right table and matched records from the left table.

SELECT students.name, enrollments.course_id
FROM students
RIGHT JOIN enrollments ON students.id = enrollments.student_id;
💡 Tip: INNER JOIN is the most commonly used join type. It only returns rows where there's a match in both tables.

Aggregate Functions

Aggregate functions perform calculations on multiple rows and return a single result.

Common Aggregate Functions

COUNT()

Counts rows

SELECT COUNT(*)
FROM students;

SUM()

Adds values

SELECT SUM(age)
FROM students;

AVG()

Calculates average

SELECT AVG(age)
FROM students;

MAX() / MIN()

Finds highest/lowest

SELECT MAX(age)
FROM students;

GROUP BY

GROUP BY groups rows with the same values into summary rows.

-- Count students by major
SELECT major, COUNT(*) AS student_count
FROM students
GROUP BY major;

-- Average age by grade
SELECT grade, AVG(age) AS avg_age
FROM students
GROUP BY grade;

HAVING

HAVING filters groups (similar to WHERE, but for aggregated data).

-- Find majors with more than 1 student
SELECT major, COUNT(*) AS count
FROM students
GROUP BY major
HAVING COUNT(*) > 1;
